# Analysis Index

The notebooks are kept at this level so the project summaries can be opened
without navigating into implementation packages.

## Notebooks

- `comprehension_fixation_analysis.ipynb`: combined-wave exploratory analysis.
- `comprehension_fixation_by_wave.ipynb`: separate Wave 1 and Wave 2 analysis.
- `individual_differences_analysis.ipynb`: standalone audit and descriptive analysis of participant measures.
- `integrated_analysis.ipynb`: exploratory cross-dataset moderation analysis.

The comprehension/fixation code lives in `comprehension/`. The individual-
differences code lives in `individual_differences/`. Cross-dataset models live
in `integrated/` and are intentionally separate from the standalone analyses.
