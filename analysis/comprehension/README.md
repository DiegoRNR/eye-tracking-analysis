# Comprehension and Fixation Analysis

This module analyzes the association between text comprehension and fixation
behavior. It uses the participant-text tables generated by
`scripts/prepare_comprehension_fixations.py`.

## Run

From the repository root:

```bash
python analysis/comprehension/run_analysis.py --wave both
```

Use `--wave 1` or `--wave 2` for a wave-specific analysis. Results are written
to `analysis/comprehension/output/`.

For a single-file exploratory view of the data, open
`../comprehension_fixation_analysis.ipynb`. It includes coverage, distributions,
text- and language-stratified plots, participant-level plots, model diagnostics,
and sensitivity comparisons. It reads the same count tables as the CLI and
saves notebook figures under `output/notebook/`.

For simpler wave-specific comparisons, open
`../comprehension_fixation_by_wave.ipynb`. It displays Wave 1 and Wave 2 in
separate vertical sections, uses shared fixation-rate scales, and fits the
models independently without merging the observations.

## Models

- `primary_negative_binomial_gee`: valid fixation events predicted by
  comprehension score, with text length as an offset and participant-clustered
  exchangeable working correlation.
- `reverse_binomial_gee`: comprehension proportion predicted by fixation rate,
  with each text's two comprehension questions represented as Bernoulli
  observations.
- `sensitivity_no_extreme_duration`: primary model excluding groups containing
  fixation durations above 2,000 ms.

The primary model reports exponentiated coefficients as rate ratios. A value
below one for `comprehension_score` supports the hypothesis that better
comprehension is associated with fewer fixation events per word.

The waves are independent samples. The analysis does not interpret the
association causally.
